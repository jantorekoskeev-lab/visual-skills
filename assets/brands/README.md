# Brand assets — BAUCHEM, ROADEX, INTENSO

Логотипы и фирменные цвета для вёрстки TDS, коммерческих предложений и презентаций.
Все PNG с суффиксом `_transparent` / `_for_dark` имеют прозрачный фон.

## BAUCHEM (Construction Chemicals)

| Файл | Назначение |
|---|---|
| `bauchem/bauchem_logo_navy_on_white.png` | основной логотип на белом фоне (шапка TDS) |
| `bauchem/bauchem_logo_navy_transparent.png` | то же, прозрачный фон |
| `bauchem/bauchem_logo_white_transparent.png` | белый логотип для синего/тёмного фона |
| `bauchem/bauchem_letterhead_band.png` | шапка фирменного бланка (синяя полоса с логотипом, 2552×367, под ширину A4) |

Цвета: синий `#20338C`, оранжевый акцент `#EE7622`, текст `#1C2230`, серый `#5B6472`, фон панелей `#F4F6FA`.
Коды документов: `BC-TDS-<продукт>-<язык>` (например `BC-TDS-301-SP-EN`). Сайт: www.bauchem.uz.

## ROADEX (дорожные присадки)

| Файл | Назначение |
|---|---|
| `roadex/roadex_logo.png` | логотип на белом фоне, обрезанный по контуру (шапка TDS) |
| `roadex/roadex_logo_transparent.png` | прозрачный фон |
| `roadex/roadex_logo_white_for_dark.png` | текст белый, знак оранжевый — для чёрного фона (презентации) |

Цвета: оранжевый `#FF8500`, чёрный `#141414`, текст `#1F1F1F`, серый `#6B6B6B`, фон панелей `#F6F6F7`.
Коды документов: `RX-TDS-<продукт>-<язык>`, КП — `RX-KP-<дата>-<№>`. Подпись в футере: «ROADEX — дорожные присадки».
